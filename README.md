# 🛠️ JavaScript Playground

A simple interactive demo built with HTML, CSS, and JavaScript to showcase various front-end concepts.

---

## 📝 Features

- **Event Handling**: Click, double-click, hover, and keypress events.
- **Form Validation**: Validates name, email, and password fields with:
  - Real-time feedback
  - Submission validation
  - Auto-reset after successful submission
- **Interactive Elements**:
  - Button text change on click
  - Button spin animation on double-click
  - Tabs that switch content dynamically
- **Background Image Slider**:
  - Full-page background image changer
  - Smooth fade animation
  - Controlled by a "Next" button

---

## ⚙️ Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6)**

---

## 🧪 How to Use

1. Open `index.html` in your browser.
2. Explore all interactive elements and features directly on the page.
